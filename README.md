# 🍃 ¿Qué cocino hoy? - Versión de Marina

## Descripción

¿Qué cocino hoy? es una aplicación web que permite encontrar recetas
a partir de los ingredientes que tenemos disponibles en casa.

El usuario introduce los ingredientes y la aplicación muestra
las recetas compatibles, indicando cuáles puede preparar y qué
ingredientes le faltan.

## Tecnologías utilizadas

- HTML5: estructura de la aplicación.
- CSS3: diseño y presentación.
- JavaScript: funcionalidades y búsqueda de recetas.
- GitHub: control de versiones y colaboración.

## Funcionalidades

- Añadir y eliminar ingredientes.
- Buscar recetas según los ingredientes disponibles.
- Ordenar las recetas según las coincidencias.
- Identificar los ingredientes que faltan.
- Consultar el tiempo de preparación.
- Mostrar las instrucciones de cada receta.
- Limpiar la búsqueda.

## Instalación y ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo index.html en un navegador.

No necesita base de datos ni instalación de dependencias.

## Colaboración

El proyecto se desarrolla utilizando GitHub.

Los integrantes trabajan en ramas independientes, registran
sus modificaciones mediante commits y utilizan Pull Requests
para revisar e integrar los cambios.
